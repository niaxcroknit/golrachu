# 골라츄 웹 버전

링크 하나로 누구나 로그인 없이 열 수 있는 버전이에요.

## 올리는 방법 (Netlify)

1. https://app.netlify.com/drop 에 들어가요. (물잔소리 올릴 때 쓴 계정으로 로그인)
2. 압축을 푼 **golrachu-web 폴더**를 통째로 화면에 끌어다 놓아요.
3. 잠시 뒤 `어쩌구.netlify.app` 주소가 생겨요. 이 링크를 공유하면 끝이에요.
4. 주소를 예쁘게 바꾸려면 **Site configuration → Change site name**에서 `golrachu`처럼 바꿔요. (이미 쓰는 사람이 있으면 다른 이름으로)

## 고친 버전을 다시 올릴 때

새 사이트를 만들지 말고, 기존 사이트의 **Deploys** 탭에 새 폴더를 끌어다 놓아요. 주소는 그대로 유지돼요.

## 폰 홈 화면에 앱처럼 추가하기

- **아이폰**: 사파리로 링크 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: 크롬으로 링크 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)

홈 화면에서 열면 주소창 없이 앱처럼 열리고, 한 번 열어 둔 뒤에는 인터넷이 없어도 쓸 수 있어요.

## 알아 둘 것

- 선택지는 저장되지 않아요. 앱을 열 때마다 빈 상태로 시작해요.
- 서버로 가는 데이터는 없어요.

## 개인정보처리방침 페이지

`privacy.html`이 플레이스토어·앱스토어에 넣을 개인정보처리방침이에요. 문의 이메일까지 다 채워 뒀어요.
GitHub Pages가 켜져 있으면 주소는 `https://niaxcroknit.github.io/golrachu/privacy.html` 이고 (Netlify에 올리면 `https://내사이트주소.netlify.app/privacy.html`), 이 주소를 Play Console의 **앱 콘텐츠 → 개인정보처리방침** 칸에 넣으면 돼요.
